UTILITY DASHBOARD

How to use:
1. Double-click UtilityDashboard.exe
2. Wait for your web browser to open automatically
3. Use the dashboard in the browser window
4. When finished, close the dashboard browser tab and the app window

If Windows shows a security warning:
1. Click "More info"
2. Click "Run anyway"

If nothing opens:
1. Wait up to 30 seconds
2. Open this address in your browser:
   http://127.0.0.1:8501
3. If that does not work, close the app and open UtilityDashboard.exe again

Important:
- Keep UtilityDashboard.exe in this folder
- Do not rename supporting files in this folder
- No Python or package installation is needed
